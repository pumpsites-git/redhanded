# Florida Department of Corrections — Public Records Request
## Sentencing Judge Data from Criminal Punishment Code Scoresheets

**Send to:** PublicRecords@fdc.myflorida.com  
**Subject:** Public Records Request — Sentencing Judge Field from OBIS/Scoresheet Data

---

Dear Florida Department of Corrections Public Records Custodian,

Pursuant to Florida Statute §119.07 (Florida's Public Records Act / "Sunshine Law"), I am requesting the following public records:

### Records Requested

The **sentencing judge name** field from Criminal Punishment Code scoresheets that have been transmitted to the Department of Corrections by clerks of the circuit court pursuant to F.S. §921.0024(2).

Specifically, I request a data extract containing the following fields for all felony offenders currently in the OBIS (Offender Based Information System) database:

1. **DC Number** (offender identifier — already publicly available in your OBIS download)
2. **Sentencing Judge Name** (as recorded on the Criminal Punishment Code scoresheet, Field 4: "Record the full name of the judge imposing sentence")
3. **Case Number** (court docket number — already publicly available in your OBIS download)
4. **County of Conviction** (already publicly available in your OBIS download)
5. **Date Adjudicated** (already publicly available in your OBIS download)

### Basis for Request

- The Criminal Punishment Code Scoresheet Preparation Manual instructs preparers to "Record the full name of the judge imposing sentence" (Field 4).
- F.S. §921.0024(2) requires clerks to transmit complete digitized scoresheets to the Department of Corrections.
- The sentencing judge's name is a matter of public record — it appears in open court proceedings, court dockets, and published court orders.
- The OBIS database download currently includes DC Number, Case Number, County of Conviction, Date Adjudicated, and offense details — but does not include the sentencing judge name. This request asks only for the addition of this one field.

### Preferred Format

A tab-delimited text file (.txt) or CSV file matching the format of your current OBIS public download, with the DC Number as the linking key. This would allow easy cross-reference with the existing publicly available OBIS data.

### Scope

All records in the current OBIS database (Active Inmates, Released Inmates, and Offenders under community supervision) where a sentencing judge name is recorded.

### Cost

I understand there may be a reasonable charge for extensive use of information technology resources per F.S. §119.07(4)(d). Please provide an estimate of any costs before proceeding. I am willing to pay reasonable costs for this data.

### Legal Notes

- Per F.S. §119.07(1)(a), "Every person who has custody of a public record shall permit the record to be inspected and copied by any person desiring to do so."
- The sentencing judge's name is not exempt from public disclosure under any provision of Florida law.
- Per F.S. §119.07(1)(c), you have a duty to respond to this request "within a reasonable time."

## Notes for Bryan

**Why this matters:** FDC receives the sentencing judge name on every Criminal Punishment Code scoresheet. The OBIS database has 708,578 offender records (91K active inmates + 479K released + 139K offenders). If they provide the judge field, we can link it to all 1,081,098 case numbers we already have from OBIS, and cross-reference with our 3.6M FDLE records.

**Expected timeline:** Florida law requires response "within a reasonable time." Government agencies typically respond within 5-10 business days. They may ask for clarification or provide a cost estimate first.

**Backup plan:** If FDC claims the judge name isn't in their digital system (unlikely given it's a required scoresheet field), we file the same request with the Florida Office of State Courts Administrator (OSCA), which maintains CCIS (Comprehensive Case Information System).
